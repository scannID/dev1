# QR Code Security Analysis & Vulnerabilities

## Executive Summary

Your QR code system has **CRITICAL SECURITY ISSUES** that allow tenants to manipulate data and access unauthorized information. This document outlines all vulnerabilities and provides recommended fixes.

## 🚨 CRITICAL VULNERABILITIES

### 1. **PREDICTABLE QR TOKEN GENERATION (HIGH RISK)**

**Location:** `QrCodeService.java:generateUniqueToken()`

```java
private String generateUniqueToken() {
    SecureRandom random = new SecureRandom();
    for (int attempt = 0; attempt < 20; attempt++) {
        byte[] bytes = new byte[6];  // ⚠️ ONLY 6 BYTES = 48 bits
        random.nextBytes(bytes);
        String token = "QR-" + HexFormat.of().withUpperCase().formatHex(bytes)
                + "-" + Instant.now().getEpochSecond();
        // ...
    }
}
```

**Problems:**
- Only 6 bytes (48 bits) of randomness → 2^48 = ~281 trillion possible values
- **Timestamp is PUBLIC** and makes it easier to brute force
- Format: `QR-XXXXXXXXXXXX-1737513600` (timestamp is visible and predictable)
- An attacker knowing when a QR was generated can reduce search space significantly

**Attack Scenario:**
1. Tenant sees their QR code: `QR-A1B2C3D4E5F6-1737513600`
2. They know timestamp is around creation time
3. They can brute force 2^48 combinations to find other merchants' QR codes
4. Once found, they can access other merchants' menus and data

**Exploitation:**
```bash
# Attacker script to enumerate QR codes
for hex in $(generate_hex_range); do
    for timestamp in $(recent_timestamps); do
        curl "https://api/qr/QR-${hex}-${timestamp}"
    done
done
```

## 🛡️ RECOMMENDED SECURITY FIXES

### Fix 1: Use Cryptographically Secure, Non-Predictable Tokens

**Replace this:**
```java
byte[] bytes = new byte[6];  // 48 bits
String token = "QR-" + hex + "-" + timestamp;  // Predictable
```

**With this:**
```java
byte[] bytes = new byte[32];  // 256 bits = cryptographically secure
SecureRandom.getInstanceStrong().nextBytes(bytes);
String token = "QR-" + Base64.getUrlEncoder().withoutPadding().encodeToString(bytes);
// Example: QR-8fK3mN9pL2dQ7xR4vT6wY1sZ5cA0hJ8bE4gU7iO9k
```

**Benefits:**
- 2^256 possible values = impossible to brute force
- No timestamp = no information leakage
- URL-safe Base64 encoding
- Conforms to OWASP token generation standards

### Fix 2: Implement HMAC-Signed QR Tokens

**Add signature verification:**

```java
public class SecureQrToken {
    private static final String SECRET_KEY = System.getenv("QR_SIGNING_KEY"); // From secure config
    
    public static String generateSecure(String merchantId, Instant expiry) {
        String payload = merchantId + "|" + expiry.getEpochSecond();
        String signature = hmacSha256(payload, SECRET_KEY);
        return Base64.getUrlEncoder().encodeToString(
            (payload + "|" + signature).getBytes()
        );
    }
    
    public static String verifyAndExtract(String token) throws SecurityException {
        byte[] decoded = Base64.getUrlDecoder().decode(token);
        String[] parts = new String(decoded).split("\\|");
        if (parts.length != 3) throw new SecurityException("Invalid token format");
        
        String merchantId = parts[0];
        long expiry = Long.parseLong(parts[1]);
        String signature = parts[2];
        
        // Verify signature
        String expected = hmacSha256(merchantId + "|" + expiry, SECRET_KEY);
        if (!MessageDigest.isEqual(expected.getBytes(), signature.getBytes())) {
            throw new SecurityException("Invalid signature");
        }
        
        // Verify expiry
        if (Instant.now().getEpochSecond() > expiry) {
            throw new SecurityException("Token expired");
        }
        
        return merchantId;
    }
    
    private static String hmacSha256(String data, String key) {
        try {
            Mac mac = Mac.getInstance("HmacSHA256");
            mac.init(new SecretKeySpec(key.getBytes(), "HmacSHA256"));
            return Base64.getEncoder().encodeToString(mac.doFinal(data.getBytes()));
        } catch (Exception e) {
            throw new RuntimeException("HMAC generation failed", e);
        }
    }
}
```

**Usage:**
```java
// Generate with 1-year expiry
String qrToken = SecureQrToken.generateSecure(
    merchantId.toString(), 
    Instant.now().plus(365, ChronoUnit.DAYS)
);

// Verify on scan
@GetMapping("/qr/{token}")
public Response scan(@PathVariable String token) {
    try {
        String merchantId = SecureQrToken.verifyAndExtract(token);
        // Proceed with verified merchant
    } catch (SecurityException e) {
        throw new ApiException(403, "Invalid or expired QR code");
    }
}
```

**Rotation Service:**
```java
@Service
public class QrRotationService {
    
    @Scheduled(cron = "0 0 0 1 * ?")  // 1st of every month
    public void rotateAllQrTokens() {
        List<RentUnit> units = unitRepository.findAll();
        for (RentUnit unit : units) {
            rotateToken(unit);
        }
    }
    
    @Transactional
    public void rotateToken(RentUnit unit) {
        // Keep old token for 30-day grace period
        unit.setQrTokenPrevious(unit.getQrToken());
        
        // Generate new token with 13-month expiry
        String newToken = SecureQrToken.generateSecure(
            unit.getId(),
            Instant.now().plus(395, ChronoUnit.DAYS)
        );
        
        unit.setQrToken(newToken);
        unit.setQrTokenIssuedAt(Instant.now());
        unit.setQrTokenExpiresAt(Instant.now().plus(395, ChronoUnit.DAYS));
        
        unitRepository.save(unit);
        
        // Notify landlord to reprint QR codes
        notificationService.send(unit.getProperty().getOwnerEmail(),
            "QR codes rotated for " + unit.getUnitNumber());
    }
}
```

**Validation with grace period:**
```java
public RentUnit findByQrTokenWithGracePeriod(String token) {
    // Check current token
    Optional<RentUnit> byToken = unitRepository.findByQrToken(token);
    if (byToken.isPresent() && !isExpired(byToken.get())) {
        return byToken.get();
    }
    
    // Check previous token (30-day grace)
    Optional<RentUnit> byPrevious = unitRepository.findByQrTokenPrevious(token);
    if (byPrevious.isPresent()) {
        RentUnit unit = byPrevious.get();
        Instant graceExpiry = unit.getQrTokenIssuedAt().plus(30, ChronoUnit.DAYS);
        if (Instant.now().isBefore(graceExpiry)) {
            return unit;
        }
    }
    
    throw new ApiException(404, "QR code expired or invalid");
}
```

**Filter implementation:**
```java
@Component
public class QrRateLimitFilter extends OncePerRequestFilter {
    
    private final StringRedisTemplate redis;
    
    @Override
    protected void doFilterInternal(HttpServletRequest request, 
                                     HttpServletResponse response,
                                     FilterChain chain) throws ServletException, IOException {
        
        if (request.getRequestURI().startsWith("/api/public/rent/") ||
            request.getRequestURI().contains("/qr/")) {
            
            String key = "rate:" + getClientId(request);
            Long count = redis.opsForValue().increment(key);
            
            if (count == 1) {
                redis.expire(key, 60, TimeUnit.SECONDS);
            }
            
            if (count > 60) {  // 60 requests per minute per IP
                response.setStatus(429);
                response.getWriter().write("{\"error\":\"Rate limit exceeded\"}");
                return;
            }
        }
        
        chain.doFilter(request, response);
    }
    
    private String getClientId(HttpServletRequest request) {
        // Combine IP + User-Agent to prevent spoofing
        String ip = request.getHeader("X-Forwarded-For");
        if (ip == null) ip = request.getRemoteAddr();
        String userAgent = request.getHeader("User-Agent");
        return DigestUtils.sha256Hex(ip + ":" + userAgent);
    }
}
```

```java
@Service
public class QrAuditService {
    
    @Async
    public void logScan(String token, HttpServletRequest request, String outcome) {
        QrScanAudit audit = new QrScanAudit();
        audit.setQrToken(hashToken(token));  // Store hash, not plaintext
        audit.setAction("SCAN");
        audit.setIpAddress(request.getRemoteAddr());
        audit.setUserAgent(request.getHeader("User-Agent"));
        audit.setOutcome(outcome);
        audit.setScannedAt(Instant.now());
        
        auditRepository.save(audit);
        
        // Alert on suspicious activity
        if (isSuspicious(audit)) {
            alertService.notify("Suspicious QR scan detected: " + audit);
        }
    }
    
    private boolean isSuspicious(QrScanAudit audit) {
        // Check for:
        // - Multiple failed scans from same IP
        // - Rapid scanning pattern
        // - Known malicious user agents
        long recentFails = auditRepository.countByIpAndOutcomeAndTimestamp(
            audit.getIpAddress(), 
            "DENIED", 
            Instant.now().minus(5, ChronoUnit.MINUTES)
        );
        return recentFails > 10;
    }
}
```

### Fix 8: Implement Token Blacklisting

```java
@Service
public class QrBlacklistService {
    
    private final StringRedisTemplate redis;
    private static final String BLACKLIST_KEY = "qr:blacklist:";
    
    public void blacklist(String token, String reason) {
        redis.opsForValue().set(
            BLACKLIST_KEY + token, 
            reason, 
            365, 
            TimeUnit.DAYS
        );
        
        // Also log to database for persistence
        BlacklistedToken bt = new BlacklistedToken();
        bt.setToken(hashToken(token));
        bt.setReason(reason);
        bt.setBlacklistedAt(Instant.now());
        blacklistRepository.save(bt);
    }
    
    public boolean isBlacklisted(String token) {
        return redis.hasKey(BLACKLIST_KEY + token);
    }
    
    public void checkToken(String token) {
        if (isBlacklisted(token)) {
            auditService.logBlacklistedAttempt(token);
            throw new ApiException(403, "This QR code has been revoked");
        }
    }
}
```

**Usage in controllers:**
